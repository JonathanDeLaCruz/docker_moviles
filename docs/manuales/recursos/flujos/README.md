# Fuentes de los diagramas

`flujos.json` conserva los pasos, el área responsable y las notas de cada recorrido. Los archivos `.mmd` conservan una versión Mermaid editable. Los manuales muestran las imágenes PNG de `../../imagenes/`, sin depender de la ejecución de Mermaid por el visor.

Todos los diagramas utilizan cajas azules, flechas verticales y el mismo ancho. Al modificar un flujo, actualiza su imagen, su fuente editable y la explicación del manual.
