# Fuentes de los diagramas

`flujos.json` define los nodos, las conexiones, sus etiquetas y la distribución de cada diagrama. Los archivos `.dot` conservan el diseño del grafo y los `.mmd` una versión Mermaid editable. Los manuales muestran los PNG de `../../imagenes/`.

El recorrido principal se lee de arriba hacia abajo. Las decisiones, los caminos alternativos, los intercambios de datos y los retornos se representan mediante ramas y flechas. Todos utilizan el mismo estilo de cajas azules y texto claro.

Al modificar un flujo, actualiza su imagen, sus fuentes editables y la explicación del manual.
